Research Methodology

BrainGAN-SRNet Methodology

An explainable deep learning framework for brain tumor classification from MRI images.

1. MRI Preprocessing

Brain MRI images are resized to 224 × 224 pixels and converted to three-channel input before normalization.

2. AC-GAN Augmentation

Auxiliary Classifier GAN is used during model development to generate synthetic samples for underrepresented tumor classes and improve class balance.

3. ResNet50 Classification

A transfer-learning-based ResNet50 classifier categorizes MRI images into Glioma, Meningioma, and Pituitary tumor classes.

4. Prediction

The trained model produces class probabilities and identifies the class with the highest predicted probability.

5. Grad-CAM XAI

Grad-CAM generates a visual explanation highlighting image regions that influenced the model's classification decision.

6. Web Deployment

The trained BrainGAN-SRNet classifier and Grad-CAM explanation module are integrated into this Django application for research-oriented MRI analysis.
